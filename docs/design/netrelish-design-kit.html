Sealed to Reference

The Seal — the one signature animation

Card lifts, shrinks toward the active jar, the lid caps it, one drip runs, a toast confirms. 900 ms on one curve. The tab in the strip collapses at the same time so the tab count visibly drops.

Sink is its quieter sibling: an idle tab dims and slides into the tray over 600 ms.

Reduced motion: both become 200 ms crossfades. No bounce, no parallax, no pulsing glows.

Do / Don't

● Do

  • Jar glyph for every jar
  • One relish button per view
  • Lip on the active tab only
  • Hairlines between regions
  • The mark, unchanged, one shadow
  • System glyphs at 1.7 stroke
  • Sentence case

● Don't

  • Folder icons, emoji, or colored dots for jars
  • Relish outlines, text, or backgrounds
  • Lips on hover or on every tab
  • Panel shadows, cards inside cards
  • Tinted, rotated, cropped, or animated marks
  • Mixed icon sets, filled icons
  • Title Case, ALL CAPS labels
