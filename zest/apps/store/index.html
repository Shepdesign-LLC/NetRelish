How it works

One file. Every tool reads it.

Your brand leaves the studio as a token file. It isn't a mood board or a PDF nobody opens — it's the thing the tools actually run on.

zest-brand.json

{
  "name": "Shepdesign",
  "fonts": { "head": "Bricolage",
             "body": "Geist" },
  "light": { "primary": "#1f4ed8",
             "ink": "#1b2130",
             "paper": "#f2f3f5" },
  "dark":  { … },
  "radius": 8,
  "type": { "base": 16, "ratio": 1.25 }
}
→
ZestMail — becomes a brand. Every block re-skins.
Zest MD — becomes a document skin, light and dark.
ZestImage — becomes an image kit with your logo.
And out the other side: CSS variables, a Tailwind config, Figma variables, WordPress theme.json, Bricks classes. The work isn't trapped in a canvas.
The tools

Four tools. One system underneath.

Each one runs on its own in a browser tab, free. Together they share a brand.

Zest

Ready — in use
The studio · Lemon

Color, type, spacing and radius, built as a real system: an OKLCH engine with gamut mapping, 19 curated font pairings, contrast audited as you go. Export CSS, Tailwind, JSON, Figma, theme.json — or send it straight to the other tools.

  • OKLCH palettes with six harmonies
  • 38 fonts, 19 pairings, custom upload
  • Modular type and spacing scales
  • WCAG audit on every pair
  • One-page brand sheet for clients

ZestMail

Ready — in use
Email builder · Orange

Drag blocks, click any text to edit it in place, switch brand and the whole email re-skins. Outputs table-based HTML that survives Outlook, with your ESP’s real merge tags already in the footer.

  • 13 blocks, 7 templates, saved modules
  • Unlimited brands, one per site
  • Bento Liquid tags, or your own
  • Outlook simulation before you send
  • Linter that explains every flag

Zest MD

Ready — in use
Markdown reader · Lime

Drop a Markdown file and read it typeset. Seven skins plus your own, code, math, diagrams, tables. Export a self-contained HTML document, print a PDF, or publish it to a link in your own skin.

  • Offline — the parser is in the file
  • Skins built from your brand tokens
  • Copy button on every block
  • Self-contained HTML export
  • Publish to a shareable page

ZestImage

In design
Featured images · Grapefruit

Branded hero images, OG cards and social tiles composed from your tokens — typography, color, logo, structure. One title renders every size, with alt text, filename pattern and metadata written into the file.

  • 8 layouts, every platform size
  • Alt text required before export
  • XMP/EXIF written into the file
  • OG meta snippet copied alongside
  • Rebrand once, regenerate the set
Why not just generate it

Because your client can tell.

There's a wave of tools that take your brand guide, run a prompt, and hand back fifty assets. They're fast, and everything they make has the same fingerprint on it. Zest goes the other way.

Generative toolsZest
How it looksEvery asset carries the model’s fingerprint. Clients notice.Typography, color and your logo. There is no model in the loop.
Doing it twiceSame prompt, different result. You cannot reproduce last month’s hero.Same tokens, same output. Every time.
RebrandingRegenerate everything and hope. Then fix it by hand.Change four colors. Regenerate the set.
Where it livesTheir cloud, your credits, their canvas.Your browser. Cloud only for sync and publishing.
What you keepImages.Tokens — CSS, Tailwind, Figma, WordPress, and the images.

Zest does use AI, in one place and optionally: drafting copy or a first layout you then edit. It's your key or your plan's drafts, it says which model it used, and the output goes through the same checks as anything you paste. You review it. You own it.
