Zest · ecosystem icons · v1

Four fruits, one material.

NetRelish set the language: a dark squircle, steel hardware, and a glossy, dripping, seeded material with real depth. Zest speaks it. The material is citrus — a different fruit for every tool — and the hardware says what the tool does.

Built as layered SVGs for Apple's Icon Composer. Glow, gloss, specular, drips, and the grated-zest flecks that are the family's signature.

01 · The material language

Inherited from NetRelish, then made citrus.

The squircle

The same superellipse as the NetRelish mark, tinted toward each fruit's hue at near-black, with a soft radial glow in the fruit color. Four backgrounds, one shape.

The steel

Identical gradients to the parent's cog — #CBD2DA → #848D99 for faces, #59626D → #39404A for edges. Never warmed or cooled. This is what says "same family" before anyone reads a name.

The fruit

Where NetRelish has goop and seeds, Zest has a wedge, a peel twist, juice drips, and grated flecks. Peel down, gloss up. The flecks are the signature — small, four to six, always near the fruit.

07 · Icon Composer

Layer order and lift.

  • background — the squircle and glow. No lift, no specular. This is the base layer.
  • hardware — the steel object. Medium lift; let Composer's specular catch the gloss band.
  • fruit — wedge, twist, drips, flecks. Highest lift, full specular, slight translucency on the flesh.
  • highlight — the hairline rim. Keep as a separate top layer so it survives dark/tinted modes.

Import each layer from layers/<icon>/. Set the canvas to the squircle mask. For the tinted appearance, Composer will use the fruit hue; for mono, drop in the glyph from mono/. Export the 1024 PNG from png/ for App Store Connect if you skip Composer entirely.
