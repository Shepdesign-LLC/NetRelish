# Resources/Zest — to be generated, never hand-edited

This folder is where the four free Zest tools will ship inside NetRelish.app: Studio at the
root, then `mail/`, `md/` and `image/`, each with its own `index.html`. The Zest window
(Window › Zest) serves it read-only on `zest://app/` (`Sources/Zest/`). Today it holds only
this README, so the window shows its not-in-this-build page.

It will be generated by `zest/build.sh --app` (phase 2, ADR 0033) from the tools under
`zest/apps/`. That option doesn't exist yet. Once it does, change the tools there and
rebuild; don't edit the files here by hand.

`project.yml` adds this folder to the app as a folder reference, not a flat group, so the
four `index.html` files keep their folders in the bundle instead of colliding at the top of
`Contents/Resources`. This README ships in the bundle; it is plain text and nothing loads it.

Decisions: `docs/adr/0015-zest-inside-netrelish.md`, `docs/adr/0033-zest-ships-in-1-0.md`.
How the host works and where it bites: `docs/subsystems/zest-window.md`.
